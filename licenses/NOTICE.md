# Source and license boundaries

The MIT license at the repository root covers the original implementation,
synthetic inputs/results and original proof documentation in this repository.
It does not relicense the scholarly sources cited in the evidence ledger.
No externally authored scientific implementation or copyrighted source-paper
PDF is included. Publications were consulted through publicly accessible primary
publisher/author records and are attributed in the literature record.

Python's standard library is a runtime dependency, not redistributed here.
The supplied IEEEtran class and bibliography style are in the separate project
paper directory, not required by this standalone repository. Their original
LPPL 1.3 and copyright notices remain inside those unmodified files. LaTeX,
TikZ and PGFPlots are external build dependencies for the paper, not scientific
baselines and not bundled with this repository.

Public accessibility does not imply permission to redistribute a source paper.
License entries marked unknown or not established explicitly forbid inferring
such permission. Stable scholarly identifiers identify consulted sources; they
are not a promise that a future network fetch will succeed.
